# INFO 612: Advanced GIS
## Overview
This course covers more advanced GIS methods, including developing GIS skills in Python. It is a continuation of INFO 609: Intro to GIS. The syllabus is available [here](https://drive.google.com/file/d/16f6q5wSLeWf3ZJfuzIg_wHsHOdFa37ZO/view?usp=drive_link), and the course Canvas page is [here](https://pratt.instructure.com/courses/49755).

## Outline
The course workshops are primarily based on Python Notebooks designed to run through ArcGIS Pro desktop software, on ArcGIS Online cloud services, or through general purpose notebook environments such as Google Colab. The workshop schedule is organized as follows:

_Learning Python for GIS_
- Week 1: Getting Started
    - Getting started with Python in ArcGIS Pro
    - Getting started with Notebooks in ArcGIS Pro
